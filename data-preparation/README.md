## Data Preparation

This directory contains scripts and notebooks used to prepare the data used to the run experiments presented in CLIPFILTER.

- The [instacities_dataset](./instacities_dataset/README.md) directory contains steps to download the Instacities dataset and a script to select the prescribed subset of images used for zero-shot city localisation.
- The [osv5m_dataset](./osv5m_dataset/README.md) directory contains scripts to download, prune, and apply filters to, the test section of the OSV-5M dataset.
- The [doxbench_dataset](./doxbench_dataset/README.md) directory contains scripts to download and apply filters to the DoxBench dataset.
