## Zero Shot City Localisation

This directory contains notebooks detailing how zero-shot city localisation experiments are run and results are gathered.

- [clip_outdoor_scene_quantification.ipynb](./clip_outdoor_scene_quantification.ipynb) contains methods used to quantify how semantically close an image is to an outdoor scene.
- [geoclip_output_generation.ipynb](./geoclip_output_generation.ipynb), [osmclip_output_generation.ipynb](./osmclip_output_generation.ipynb), and [streetclip_output_generation.ipynb](./streetclip_output_generation.ipynb) contain methods used to run CLIP-based models (`GeoCLIP`, `OSMCLIP`, and `StreetCLIP`, respectively) for zero-shot localisation.
